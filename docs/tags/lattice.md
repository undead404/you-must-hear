## lattice

Last updated: <time datetime="2025-12-04T09:43:35.310Z">Thu Dec 04 2025 11:43:35 GMT+0200 (Eastern European Standard Time)</time>

### Description

Lattice music, in the context of musical tuning, is a method of modeling the tuning relationships of a just intonation system. It is represented as an array of points in a periodic multidimensional pattern, where each point corresponds to a pitch or an interval with respect to some other point on the lattice. The connecting lines in a lattice display intervals as vectors, so that a line of the same length and angle always has the same intervalic relationship between the points it connects, no matter where it occurs in the lattice.
