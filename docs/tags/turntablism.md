## turntablism

Last updated: <time datetime="2025-11-22T13:41:42.494Z">Sat Nov 22 2025 15:41:42 GMT+0200 (Eastern European Standard Time)</time>

### Description

Turntablism is a hip-hop art form where DJs manipulate vinyl records as musical instruments, using techniques like scratching, beat juggling, and sampling to create original compositions. Born from 1970s block parties, it evolved into a sophisticated practice blending rhythm, texture, and found sounds. The genre ranges from abstract instrumental soundscapes to intricate percussive performances that showcase technical skill and creative sampling.
